# Classic Games 隐私政策

生效日期：2026-08-24  
English inquiries can be submitted through in-app Help & Feedback.

## 1. 我们收集的信息

- 账号：手机号、第三方身份标识、昵称、简介、地区等你提交的资料。
- 凭证：登录 token；实名认证不保存证件号原文。
- 使用数据：游玩分钟、Fork / 发布 / 浏览等分析事件、设备与语言偏好。
- 支付：订单号与权益到账状态；支付渠道令牌不经过客户端直连模型或密钥。

## 2. 使用目的

提供登录、发现、创作、社区、合规审核、反滥用、客户支持与法定审计。生成式 AI 调用在服务端完成，客户端不持有模型密钥。

## 3. 存储与传输

数据经 HTTPS 传输。密钥与数据库凭据仅存在服务端环境。生产环境拒绝开发者后门（如 `CLASSIC_GAMES_DEV_ADMIN`）。

## 4. 共享

仅在以下情况共享：你主动的社交展示、完成支付所必需的渠道、法律要求、或经去标识化的统计。

## 5. 你的权利

可查阅与更正资料、导出部分使用记录（视接口能力）、关闭营销类通知、以及注销账号。青少年模式的 PIN 由监护人保管。

## 6. 未成年人

未满法定年龄的用户应在监护人同意下使用。开启青少年模式后限制每日游玩时长与宵禁时段。

## 7. 联系

通过应用内「帮助与反馈」行使权利或提出投诉。政策更新将在本页公示。
