# Classic Games 隐私政策

生效日期：2026-08-24；2026-11-11 修订（客户端改为本地运行的启动器）

## 0. 适用范围

本仓库包含两类软件，数据处理方式不同：

- **客户端（主机风格启动器，`apps/client`）完全在本机运行。** 它没有账号和登录，不发起任何网络请求，不收集也不上传任何数据。游玩时长、最高分、收藏、最近游玩、成就、设置和按键绑定只保存在本机用户数据目录下的 `launcher.json`；设置屏可以把它导出成文件、从文件导入，或清除进度。删除该文件或卸载应用即删除全部数据。
- **在线服务（`apps/server`，经 CLI、MCP、SDK 或 HTTP API 访问）** 由其部署者运营。下面第 1 至 7 节只适用于这类服务；自行部署时，运营主体是部署者自己。

## 1. 我们收集的信息

- 账号：手机号、第三方身份标识、昵称、简介、地区等你提交的资料。
- 凭证：登录 token；实名认证不保存证件号原文。
- 使用数据：Fork / 发布 / 浏览等分析事件，以及经接口提交的游玩记录与语言偏好。
- 支付：订单号与权益到账状态。

## 2. 使用目的

提供登录、发现、创作、社区、合规审核、反滥用、客户支持与法定审计。生成式 AI 调用在服务端完成，调用方不持有模型密钥。

## 3. 存储与传输

数据经 HTTPS 传输。密钥与数据库凭据仅存在服务端环境。生产环境拒绝开发者后门（如 `CLASSIC_GAMES_DEV_ADMIN`）。

## 4. 共享

仅在以下情况共享：你主动的社交展示、完成支付所必需的渠道、法律要求、或经去标识化的统计。

## 5. 你的权利

可查阅与更正资料、导出部分使用记录（视接口能力）、关闭营销类通知、以及注销账号。青少年模式的 PIN 由监护人保管。

## 6. 未成年人

未满法定年龄的用户应在监护人同意下使用。服务保留青少年模式的设置接口（含监护人 PIN）；时长与宵禁限制由接入该服务的客户端执行，本仓库的启动器不含账号，也不含这一功能。

## 7. 联系

通过运营主体公示的联系方式行使权利或提出投诉；服务另提供反馈接口。与本仓库代码有关的问题请在代码仓库提交 issue，安全问题按 [SECURITY](../../SECURITY.md) 报告。政策更新将在本页公示。
