# Classic Games 用户协议

生效日期：2026-08-24；2026-11-11 修订（客户端改为本地运行的启动器）

运营主体以实际对外公示为准。

## 0. 适用范围

客户端（主机风格启动器，`apps/client`）是在本机运行的开源软件，按 [Apache License 2.0](../../LICENSE) 提供，没有账号，不连接任何在线服务，本协议的以下条款不适用于它。本协议适用于在线服务（`apps/server`，经 CLI、MCP、SDK 或 HTTP API 访问）；自行部署该服务时，运营主体是部署者自己。

## 1. 服务内容

在线服务提供基于 Mod DSL 的小游戏二创与发布。用户通过自然语言或编辑器修改结构化 DSL，平台不执行用户提交的任意代码。

## 2. 账号

- 可使用手机验证码、第三方账号或游客身份使用服务。
- 游客会话仅用于浏览；发布、充值、社交等能力以登录与实名策略为准。
- 用户可在设置中申请注销账号；注销后个人资料与会话不可恢复。

## 3. 用户内容

- 用户对其发布的标题、简介、评论、私信与 DSL 作品承担法律责任。
- 平台有权对内容进行机器与人工审核，并可拒绝、下架或限制传播。
- 二创（Fork）基于既有作品的补丁链；不得将他人作品宣称为完全原创。

## 4. 生成式 AI

- AI 仅在服务端生成 DSL 补丁，并经 Schema 校验后才可预览或发布。
- AI 辅助生成的作品须带有 AI 标识；用户不得去除或伪造该标识。会员权益不含关闭或隐藏该标识。

## 5. 青少年与合规

服务保留青少年模式的设置（含监护人独立 PIN）；时长与宵禁限制由接入该服务的客户端按公示规则执行。监管要求变化时，平台可调整限制而无需另行签署协议。

## 6. 付费

创作点、会员等虚拟商品一经到账，除法律强制规定外不支持退款。本仓库的客户端不含任何充值入口。

## 7. 免责

游戏为 UGC，游玩体验因作品而异。平台不对单一作品的可玩性、收益或排名作承诺。

## 8. 联系

通过运营主体公示的联系方式或服务的反馈接口提交问题；与本仓库代码有关的问题请在代码仓库提交 issue。政策更新将在本页公示。
