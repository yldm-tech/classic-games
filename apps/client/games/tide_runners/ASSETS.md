# Assets of `tide_runners`

All in-game art is original pixel art authored in code for this project: the sprites are rows of palette characters and painted shapes in `gfx.gd`, the tiles and backdrops are painted by `scenery.gd`, and both are built into textures at run time. All sound effects and music are original and synthesised at run time by `games/shared/game_audio.gd` from the data in `sounds.gd`. The only asset files are the two pictures below.

| File | What it is | Source | Licence |
|---|---|---|---|
| `key_art.jpg` | 16:9 key art for the launcher and the website | Generated with the `doubao-seedream-5.0-pro` image model from a prompt written for this project that describes the game's own characters and setting; original composition, no third-party material | Apache-2.0, with the project; AI-generated image |
| `site_screenshot.png` | In-game screenshot for the website | Captured from this game with `scripts/run-launcher-shot.sh` | Apache-2.0, with the project |
