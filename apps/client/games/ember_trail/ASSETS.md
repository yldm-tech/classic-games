# Assets of `ember_trail`

Every file in this directory that is not code or the manifest, with where it came from and the licence it is distributed under.

| File | What it is | Source | Licence |
|---|---|---|---|

All in-game pictures (the lamplighter, the ashhorn, creatures, guardians, tiles, props and backdrops) are built at run time by `art.gd` from the palette in `palette.gd`: some from rows of palette characters written by hand in `sprite_data.gd`, the rest painted by code. All sound effects and music are synthesised at run time by `games/shared/game_audio.gd` from the specs in `sounds.gd`. None of it is a file, so none of it is listed above.
