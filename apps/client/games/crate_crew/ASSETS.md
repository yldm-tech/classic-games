# Assets of `crate_crew`

Every file in this directory that is not code or the manifest, with where it came from and the licence it is distributed under. The pictures and the music were made for this project on 2026-11-11 with the tools in `scripts/assets/`, from prompts written for this project that describe its own squirrels, machines and workshop and name no existing work. They are distributed under Apache-2.0 with the project; see the note on AI-generated material in `docs/legal/licenses.md`.

Every picture prompt begins with the same style sentence, written `[style]` below: "Hand-painted cartoon game art, clean dark brown outlines of even weight, soft cel shading with a warm rim light, chunky rounded toy-like shapes, rich saturated colours, cosy lamp-lit workshop mood."
