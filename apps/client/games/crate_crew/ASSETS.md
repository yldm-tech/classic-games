# Assets of `crate_crew`

Every file in this directory that is not code or the manifest, with where it came from and the licence it is distributed under. The pictures and the music were made for this project on 2026-11-11 and 2026-11-12 with the tools in `scripts/assets/` and with the image and video generation services named below, from prompts written for this project that describe its own squirrels, creatures, bosses and places and name no existing work. They are distributed under Apache-2.0 with the project; see the note on AI-generated material in `docs/legal/licenses.md`.

Every picture prompt begins with the same style sentence, written `[style]` below: "Hand-painted cartoon game art, clean dark brown outlines of even weight, soft cel shading with a warm rim light, chunky rounded toy-like shapes, rich saturated colours, cosy lamp-lit workshop mood." The image model is doubao-seedream-5.0-pro and the video model doubao-seedance-2.0-fast throughout.

The recorded music is kept as a stand-in: `sounds.gd` names a music hook per place and moment (title, map, kitchen, toyshop, sewer, treehouse, boss, and the fanfares clear, victory and gameover) and points each at one of these files until its own track is made. Sound effects are not files: they are synthesised at run time by `games/shared/game_synth.gd` from the presets of `games/shared/game_sfx.gd` and the layered definitions in `sounds.gd`, written for this project. Ground edges, rope lines, shadows, particles of light, the route map's paths and badges, banners and sign plates are drawn by `render.gd`.
