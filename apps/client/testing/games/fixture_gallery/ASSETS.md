# Assets of `fixture_gallery`

Test data for the high-resolution art and recorded audio paths. Every file was made for this project on 2026-11-11 with the tools in `scripts/assets/`; the generated ones come from prompts written for this project that describe an original subject and name no existing work. They are distributed under Apache-2.0 with the project; see the note on AI-generated material in `docs/legal/licenses.md`.
