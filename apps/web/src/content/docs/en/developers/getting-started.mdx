Classic Games is a console-style launcher with a collection of original games. It is pre-release: there are no public builds and no store releases. Everything below starts from source, and every `make` target used here is defined in the <a href={repoFile('Makefile')}>Makefile</a> at the repository root.

## Prerequisites

| Tool | Version | Used for |
|---|---|---|
| Godot | 4.6.3, exactly | The launcher and the games. Use the standard build, not the .NET build. The version is pinned in `apps/client/.godot-version` and the test scripts check it |
| GNU Make | Any recent version | Single entry point |
| Go | 1.26 | Only for the optional online service: backend, CLI, MCP server and SDK. Each module's `go.mod` declares `go 1.26`, and a recent Go toolchain downloads the matching version on demand |
| Node.js and pnpm | Node 22.23.4 or newer, pnpm 12 | Only needed to build this site |

## Run the launcher

Let Godot import the project's resources first. This is needed once:

```bash
make import GODOT=/path/to/godot
```

Then start the project. Its main scene is the launcher:

```bash
/path/to/godot --path apps/client
```

You can also open `apps/client` in the Godot 4.6.3 editor and run it from there.

The launcher is operated with a gamepad or a keyboard: arrow keys or the D-pad move the focus, Enter or A confirms, Esc or B goes back, and F11 switches between console mode and PC mode. All progress is kept in one local save file. The launcher makes no network requests, so nothing else has to be running.

## The optional online service

The repository also contains a Go backend, a command-line tool, an MCP server and a Go SDK. They implement Mod DSL validation and patching and the API of an online service (accounts, catalog, mods, community, commerce). They work and are tested, but the launcher is not wired to them: skip this section if you only want to play or to work on the launcher and the games.

### Start the backend

```bash
make dev
```

The backend listens on `:8080` by default; use `PORT=9090 make dev` to change the port. The default database is a SQLite file in the working directory, so there is no database to install.

Without `ANTHROPIC_API_KEY` the backend uses a deterministic local provider in place of a model, so it starts with no keys at all. With the key set it calls the real model. Every environment variable is listed in <a href={repoFile('.env.example')}>.env.example</a> at the repository root.

Check that the backend is up:

```bash
curl http://localhost:8080/healthz
```

The API reference is served at `http://localhost:8080/swagger/index.html`.

### Build the CLI and the MCP server

```bash
make cli-build    # apps/cli/bin/classic-games
make mcp-build    # apps/mcp/bin/classic-games-mcp
```

The DSL commands of the CLI work offline. The others need the backend:

```bash
export PATH="$PWD/apps/cli/bin:$PATH"
classic-games dsl validate apps/client/runtime/shooter/baseline.dsl.json   # offline
classic-games server health                                                # needs the backend
classic-games auth login
classic-games mods list
```

The [CLI](/en/developers/cli/) and [MCP server](/en/developers/mcp/) pages go on from here.

## Tests and gates

| Command | What it does |
|---|---|
| `make launcher-test GODOT=/path/to/godot` | Headless launcher tests: save file, catalog, home screen focus, starting and finishing a run |
| `make settings-test`, `make library-test`, `make pc-mode-test`, `make game-flow-test` | Headless tests of the settings screen, the library and achievements, PC mode, and the game menu, HUD, pause and result flow. Each takes `GODOT=/path/to/godot` |
| `make launch-test GODOT=/path/to/godot` | Starts the main scene and checks that the launcher is assembled |
| `make boundary-test` | Client dependency-direction check, plus the checker's own tests |
| `make architecture-test` | Repository-level architecture boundary check |
| `make test` | Backend `go test` |
| `make vet` | `go vet` for every Go module |
| `make dsl-test`, `make sdk-test` | Tests of the shared Go packages |
| `make cli-test`, `make mcp-test` | Tests of the CLI and the MCP server |
| `make go-standalone` | `go vet` and `go test` for every Go module with `GOWORK=off` |
| `make ci GODOT=/path/to/godot` | Runs every Go and Godot gate in order |
| `make ci-web` | Installs, type checks and builds this site |

`make help` lists all targets.

## Build this site

This site is `apps/web` in the repository, built with Astro and Starlight. From the repository root:

```bash
pnpm install
pnpm web:dev      # local development
pnpm web:check    # type check
pnpm web:build    # static output in apps/web/dist
```
